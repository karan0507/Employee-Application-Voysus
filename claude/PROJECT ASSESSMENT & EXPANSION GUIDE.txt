  4. DATABASE MANAGEMENT (Supabase)

  How to Make Changes Securely:

  Method 1: Supabase Dashboard SQL Editor ⭐ Recommended for you
  1. Go to: https://supabase.com/dashboard
  2. Select your project
  3. Click "SQL Editor" in sidebar
  4. Write SQL → Run → Saves as migration

  Method 2: Migrations (Advanced)
  # Initialize Supabase CLI
  npx supabase init

  # Create migration
  npx supabase migration new add_status_column

  # Apply migration
  npx supabase db push

  Best Practices:
  - ✅ Always test in SQL Editor first
  - ✅ Backup before major changes: Database → Backups
  - ✅ Use transactions for multiple changes
  - ❌ Never delete job_applications table directly
  - ❌ Never drop RLS policies without replacement

  Common Operations:

  -- Add column
  ALTER TABLE job_applications
  ADD COLUMN reviewed_by UUID REFERENCES auth.users(id);

  -- Modify RLS policy
  DROP POLICY "Allow anonymous insert" ON job_applications;
  CREATE POLICY "Allow authenticated insert" ON job_applications
    FOR INSERT TO authenticated WITH CHECK (true);

  -- Create index
  CREATE INDEX idx_reviewed_by ON job_applications(reviewed_by);
